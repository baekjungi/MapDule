# MapDule (맵듈)

일정과 이동을 함께 설계하는 모바일 우선 일정 관리 UI 프로토타입입니다.

## 현재 구현 범위

- 오늘의 시간순 타임라인
- 일정 장소와 이동 경로를 보여주는 지도형 UI
- 지각 위험 알림 카드
- 이동 시간 블록과 자투리 시간 퀘스트
- AI 자연어 일정 등록 미리보기
- 약속 지점 추천 화면
- 피로도 및 휴식 제안 화면
- 모바일·데스크톱 반응형 레이아웃

일정이나 위치 샘플 데이터는 미리 채워져 있지 않습니다. 지도·교통·AI API는 아직 연결하지 않았습니다.

## 실행

요구사항: Node.js 18 이상

```bash
npm run check
npm start
```

브라우저에서 `http://localhost:4173`을 엽니다. 포트는 `PORT` 환경 변수로 바꿀 수 있습니다.

```powershell
$env:PORT=8080
npm start
```

## 배포

이 프로젝트는 빌드 단계가 없는 정적 웹앱입니다.

- 정적 호스팅: `index.html`, `styles.css`, `app.js`와 설정 파일을 업로드
- Node 호스팅: `npm start` 실행, `PORT` 환경 변수 사용
- Vercel, Netlify, GitHub Pages: 루트 디렉터리를 배포 대상으로 설정

실제 서비스로 전환하기 전에 다음 작업이 필요합니다.

1. 인증과 사용자별 일정 저장소 연결
2. 지도·장소 검색 API 서버 연동
3. 대중교통·도로 이동 시간 API 연동
4. 자연어 분석 API 연동
5. 위치 및 알림 권한 처리
6. API 키를 서버 환경 변수로 관리
7. 실제 일정 생성·이동 블록·지각 알림 테스트 추가

제품 요구사항은 [prd.md](prd.md), 개발 지침은 [agent.md](agent.md)를 참고합니다.
